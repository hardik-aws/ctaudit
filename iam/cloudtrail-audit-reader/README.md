# cloudtrail-audit-reader

Creates the least-privilege IAM policy that `ctaudit` needs to read AWS logs from one S3 bucket. It works for CloudTrail logs and for Elastic Load Balancing access and connection logs, because both are delivered under `[<prefix>/]AWSLogs/`.

The policy allows:

- `s3:ListBucket` on the bucket, only for keys under `AWSLogs/` (so the bucket root is never listed)
- `s3:GetObject` on objects under `AWSLogs/`
- `kms:Decrypt` on `kms_key_arn`, only through S3, when the trail uses SSE-KMS

It creates the policy only. Attach it to the role or user that runs `ctaudit`; `deploy/terraform/example` attaches it to an IRSA role.

## Usage

```hcl
module "ctaudit_reader" {
  source          = "./iam/cloudtrail-audit-reader"
  log_bucket_name = "org-cloudtrail-logs"
  kms_key_arn     = "arn:aws:kms:us-east-1:111122223333:key/..." # omit for SSE-S3
  policy_name     = "ctaudit-reader-cloudtrail"
  tags = {
    Owner       = "platform-team"
    Department  = "engineering"
    Project     = "example-project"
    Application = "ctaudit"
    ManagedBy   = "terraform"
  }
}
```

IAM policy names are unique per account, so give each instance its own `policy_name`. The policy document is in [`policies/reader.json.tftpl`](policies/reader.json.tftpl).

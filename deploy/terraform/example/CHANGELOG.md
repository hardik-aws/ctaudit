# Changelog

All notable changes to this module are documented here.
Format: [Keep a Changelog](https://keepachangelog.com/en/1.1.0/); versioning: [SemVer](https://semver.org/).

## [Unreleased]
### Added
- Validation for `region`, `cluster_name`, `role_name`, `log_buckets` names and keys, `image_repository`, `bucket_region`, `accounts`, `regions`, and each scanner's `name` (unique DNS label of at most 30 characters), `log_format`, `interval`, `lookback`, and `accounts`.
- A precondition that the role name is at most 64 characters.
- Module CLAUDE.md and CHANGELOG.md; README tables generated by terraform-docs.
### Changed
- **Breaking:** `image_repository` and `region` no longer have defaults and must be set.
- **Breaking:** `role_name` defaults to `ctaudit-<cluster_name>` instead of `ctaudit-reader`, so two clusters in one account do not collide. Existing roles are replaced unless `role_name` is set to the old name.
- `bucket_region` defaults to `region` instead of `us-east-1`.
- The trust policy moved from an `aws_iam_policy_document` data source to `policies/irsa-trust.json.tftpl`.
- The `helm` provider constraint is `>= 3.0` instead of `~> 3.0`.

## [0.1.0] - 2026-09-24
### Added
- Reader policies per log bucket, an IRSA role, and a `helm_release` of the local chart with the role ARN passed in.
